# Divots & Dangs — Watson Particle Game and Resonance Model

## Project status

This document reconstructs and expands the **Divots & Dangs** concept from Kris Watson's earlier work. The original game files were not located by name in the connected GitHub repositories during this pass, so this is a new integration layer rather than a claim that the prior game code was recovered verbatim.

## Core addition

The new interpretation connects Divots & Dangs directly to the Watson Particle:

- **Dang:** the raised, charged, forward, proton-like side.
- **Divot:** the indented, receiving, rearward, electron-like side.
- **Pair:** a complementary front/back geometry that can lock, repel, flip, nest, or exchange places.

```text
Dang  = projection / charge / front / compressed node
Divot = reception / cavity / back / expanded shell
```

The pair should not be treated as two unrelated pieces. They are complementary surface states of one larger relationship.

## Connection to the Watson Particle

The Watson Particle framework describes a front and back relationship:

```text
proton-like front / Eternal Flame / concentrated state
                     ↕
hydrogen-electron back / expanded shadow-shell state
```

Divots & Dangs converts this into playable geometry.

A **dang** is a local protrusion or concentrated node. A **divot** is the space, depression, or receiving geometry that can contain or organize the dang. Their interaction can represent:

- charge and response;
- signal and cavity;
- proton-like center and electron-like shell;
- hot compressed state and cold expanded state;
- instruction and memory;
- seed and soil;
- light source and shadow boundary.

## Game mechanics

### Board

The board is a field of cells. Each cell can contain:

- empty space;
- a divot;
- a dang;
- a locked pair;
- a flipped pair;
- a resonance bridge;
- a shadow-shell;
- an unstable mismatch.

### Actions

Players can:

1. Place a dang.
2. Carve or place a divot.
3. Rotate either piece.
4. Expand a divot into a shell.
5. Compress a dang into a higher-density node.
6. Match front/back geometry.
7. Trade places between a dang and divot.
8. Build chains and nested structures.
9. Trigger a resonance pulse.
10. Stabilize the board before entropy overtakes it.

### Scoring

Possible scores:

- **Fit:** geometric compatibility.
- **Charge:** available dang energy.
- **Capacity:** divot storage or shell reach.
- **Coherence:** phase agreement across a chain.
- **Balance:** ratio between projections and cavities.
- **Memory:** ability to return to a trained configuration.
- **Growth:** number of stable nested pairs.

## Seed and biological-resonance level

The cannabis-seed discussion is retained as a speculative **Resonant Precipitation** level, but not as established biology.

The game can model:

```text
mineral field
→ divot cavities
→ dang instructions
→ lattice matching
→ seed-pattern emergence
```

The level should explain that real seeds develop through reproduction, genetics, cell division, metabolism, and environmental conditions. The game uses resonance and geometry as a conceptual overlay rather than claiming seeds appear directly from minerals.

## Feather and structural-color level

Bird-feather coloration is a good real-world analogy for the game because microscopic structures can reflect different wavelengths.

In the game:

- divots act as optical cavities;
- dang spacing controls reflected color;
- changing lattice geometry changes the visible output;
- environmental inputs modify the pattern.

This module should distinguish structural coloration from pigment coloration.

## Alpha–Beta–Gamma–Delta integration

The game can use four navigation anchors:

- **Alpha:** starting geometry.
- **Beta:** active board state.
- **Gamma:** target structure.
- **Delta:** permitted shift that moves a piece outside the original alignment.

A stable move minimizes mismatch between the current pair geometry and the target vector.

## Memory-Metal integration

A trained Divots & Dangs board can remember its preferred geometry:

```text
train shape
→ disturb board
→ release constraint
→ recover remembered divot/dang arrangement
```

This connects to the Memory-Metal repository as a safe shape-memory and hysteresis analogy.
