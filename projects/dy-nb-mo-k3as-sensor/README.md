# Dysprosium–Niobium/Molybdenum–Potassium Arsenide Sensor Lab

## Purpose

This project preserves and develops Kris's layered sensor sequence as a safe research, simulation, and visualization environment.

Layer flow:

```text
(-) Dysprosium outer shell
        ↓
Aluminum buffer and current-spreading layer
        ↓
Niobium / Molybdenum split sensor shell
        ↓
Potassium arsenide core (+)
```

The project treats this as a proposed materials architecture. It separates established material properties, engineering analogies, computational simulation, and unverified hypotheses.

## Scientific status labels

Every claim, chart, and experiment must carry one of these labels:

- **Reference data** — measured or published material property.
- **Established science** — accepted mechanism such as electrical resistance, magnetization, strain, thermal drift, or spin transport.
- **Engineering analogy** — useful design metaphor that is not itself a measured mechanism.
- **Project hypothesis** — a proposed behavior requiring fabrication and testing.
- **Simulation output** — generated by the website model rather than physical hardware.
- **Experimental result** — measured with documented equipment, calibration, uncertainty, and raw data.

## Proposed architecture

### 1. Dysprosium outer shell

Proposed role: magnetic biasing and spin-sensitive boundary layer.

Research questions:

- How does temperature affect magnetization and hysteresis?
- Can a thin dysprosium-containing layer improve field sensitivity without excessive noise?
- What oxidation and encapsulation barriers are required?

### 2. Aluminum buffer

Proposed roles:

- current spreading;
- mechanical support;
- thermal equalization;
- vibration damping;
- interface isolation between reactive or dissimilar materials.

The website models aluminum as a tunable buffer rather than assuming it perfectly eliminates hot spots.

### 3. Niobium / molybdenum split

Proposed role: differential sensing pair. Two material paths are compared rather than treated as identical.

Possible measurable channels:

- resistance difference;
- phase shift;
- strain response;
- temperature drift;
- magnetic-field response;
- contact-potential difference.

The split architecture supports directional estimates only after calibration against known field orientations.

### 4. Potassium arsenide core

Potassium arsenide is treated as a proposed sensitive core material. Because potassium compounds and arsenic-containing materials can be hazardous or difficult to fabricate, the website defaults to simulation and safer substitute-material studies.

No user should attempt unsupervised synthesis. Physical work requires qualified materials scientists, sealed handling, ventilation, chemical review, and institutional safety controls.

## Safe operating envelope

The interactive model is limited to low-voltage sensing and passive diagnostics:

- nominal supply: 2–5 V;
- current-limited source;
- no radioactive sources;
- no high-energy emitters;
- no EMP or drone-disruption functions;
- no instructions for targeting people, vehicles, communications, or infrastructure.

## Carbon and stibnite extension

The second sequence is preserved as an optional isolation and signal-routing study:

```text
Sulfur (16) + Antimony (51) foundation
Phosphorus (15) + Dysprosium (66) active response layer
Potassium (19), Barium (56), Calcium (20) charge-transfer candidates
Carbon (6) isolation / electrode / protective network
```

Carbon is modeled through selectable forms such as graphite, graphene-like sheet, carbon coating, or insulating carbon composite. The simulator does not claim carbon automatically prevents every chemical reaction.

## Passive global-resonance research mode

The project may visualize atmospheric, magnetic, radio, and environmental data as maps. It must use real sensor feeds, public datasets, or simulated inputs with provenance.

Allowed outputs:

- passive field mapping;
- anomaly visualization;
- weather and ionospheric overlays;
- signal-source comparison;
- communications resilience research;
- educational NQR/NMR explanations;
- non-targeting calibration exercises.

Excluded outputs:

- global targeting;
- active disruption;
- weaponized resonance;
- EMP design;
- drone takedown;
- radioactive power-clock designs.

## Robotics integration

A robot can use the sensor as one input among several:

```text
Sensor head
→ shielded analog front end
→ differential amplifier
→ ADC
→ calibration matrix
→ confidence estimator
→ robot perception bus
```

The robot must display uncertainty and should never treat a single anomalous reading as proof of a nearby element, gravitational event, or threat.

## Experiment ladder

### Stage 0 — simulation

- Validate equations and UI.
- Generate synthetic sweeps.
- Test sensor-fusion logic.

### Stage 1 — safe surrogate materials

- Use commercial Hall, magnetoresistive, strain, and temperature sensors.
- Compare split-channel differential behavior.
- Characterize vibration and thermal drift.

### Stage 2 — thin-film research

- Performed only in a qualified laboratory.
- Document fabrication, encapsulation, microscopy, and electrical tests.

### Stage 3 — independent replication

- Publish raw data and uncertainty.
- Require independent reproduction before stronger claims.

## Security model

The website is not described as unhackable. It should use:

- no secrets in client code;
- hardware-backed or passkey authentication for private accounts;
- authenticated encryption for private data;
- signed dataset manifests;
- strict content-security policy;
- dependency pinning and scanning;
- append-only audit events;
- least-privilege service access;
- reversible releases and backups.

## Preservation rule

Recovered notes are appended and versioned. AI tools must not silently replace earlier theories, diagrams, or experiment records. Corrections should be added as labeled annotations with authorship and date.
